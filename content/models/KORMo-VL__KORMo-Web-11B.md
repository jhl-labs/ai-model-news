## 요약

**KORMo-Web-11B**는 KAIST MLP 연구실이 처음부터 구축한 KORMo 파운데이션 모델을 기반으로, **LLM·VLM·GUI Agent 능력을 모두 갖춘 범용 멀티모달 AI 모델**입니다.

- **하나의 모델, 세 가지 능력:** 일반적인 질문에는 LLM으로 답변하고, 이미지 이해가 필요한 경우 VLM으로, **웹 조작이 필요한 요청에는 GUI Agent로 작동**합니다. - **독자 파운데이션 모델 기반:** From-scratch로 학습한 KORMo-10B를 KORMo-VL로 확장하고, 기존 언어·시각 이해 능력을 유지하도록 학습한 웹 에이전트로 **생각\ 또한 유일하게 한국어**로 하는 모델입니다. - **대규모 웹 사전학습:** 1,000만 건 이상의 한영 웹 학습 샘플로 UI 요소의 위치·의미·구조·기능 등을 세밀하게 학습했습니다. - **실제 웹 행동 학습:** 10만 건 이상의 한영 웹 사용 궤적을 활용해 복잡한 다단계 웹 작업을 수행합니다. - **완전 공개 및 상업적 활용:** 모델 가중치와 학습·평가 리소스를 공개하며, **Apache-2.0 라이선스에 따라 상업적 이용과 수정·재배포가 가능**합니다.
