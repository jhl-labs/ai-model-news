## 요약

MOSS-Image-SFT is a supervised fine-tuned text-to-image model in the **MOSS-Image** family from OpenMOSS, derived from [MOSS-Image-Base](https://huggingface.co/OpenMOSS-Team/MOSS-Image-Base). It uses the same architecture and inference pipeline, supporting natural-language prompts, tag sequences, and JSON layouts for controlling text placement and object arrangement.

In this example, SFT produces clearer text grouping and a more organized whiteboard layout.

Use Python 3.10 or later and an NVIDIA GPU with CUDA support. Install a PyTorch 2.9 or later build compatible with your CUDA environment…
