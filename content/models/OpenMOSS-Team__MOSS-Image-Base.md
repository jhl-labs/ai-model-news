## 요약

MOSS-Image-Base is the base text-to-image model in the **MOSS-Image** family from OpenMOSS. It supports natural-language prompts, tag sequences, and JSON layouts for controlling text placement and object arrangement.

In this example, SFT produces clearer text grouping and a more organized whiteboard layout.
