## 요약

This repository contains models that have been converted to the GGUF format with various quantizations from an IBM Granite base model. Please reference the base model's full model card here: https://huggingface.co/ibm-granite/granite-4.0-micro-base

The examples below use the `Q4_K_M` quantization (`granite-4.0-micro-base-Q4_K_M.gguf`). Other quantizations in this repository work the same way; only the file name changes.
