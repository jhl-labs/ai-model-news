## 검증 범위와 후속 보완점

- GitHub Actions 최근 실행 조회는 공개 API 요청 제한(HTTP 403)으로 확인하지 못했다. HTTP 200은 예약 수집·배포 성공을 보장하지 않는다. 수정 워크플로의 실제 실행 검증도 배포 후 필요하다.
- 기존 글의 본문은 이번에 일괄 재생성하지 않았다. 비교 대상 선택 수정은 새 글 생성과 향후 --regenerate 실행부터 적용된다.
- 날짜는 일 단위로 저장하므로 같은 날 발행된 모델 사이의 정확한 선후관계는 복원할 수 없다.
- lastModified는 저장소 갱신 시각이다. README가 표현하는 ‘의미 있는 갱신’ 여부까지 판별하는 기능은 없다.
- Markdown 변환기는 프로젝트가 생성하는 표와 기존 부분집합을 지원한다. 임의의 복잡한 Markdown 전체 문법을 지원하지 않는다.
